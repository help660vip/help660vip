# 你好，我是 help660

一名喜欢折腾的学生开发者，平时用代码解决自己遇到的实际问题。

我主要使用 JavaScript、TypeScript 和 Python，关注 Web 应用、自动化工具、Bot 生态，以及 Linux 服务器与网络。比起做展示型 Demo，我更喜欢把一个想法真正做成能部署、能长期运行的项目。
